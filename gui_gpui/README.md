# GPUI GUI 迁移版

GPUI Kit 0.6.6 已作为独立的 workspace GUI 包接入；当前 `wqxtools` 默认入口仍是功能较完整的 egui 版，GPUI 版的可执行文件名为 `wqxtools-gpui`。

```sh
cargo run -p wqxtools-gui-gpui
cargo test -p wqxtools-gui-gpui --all-targets
cargo clippy -p wqxtools-gui-gpui --all-targets -- -D warnings
```

已迁移：GVBASIC 语法高亮、行号、真实编译诊断及红/黄波浪线；新建、打开、保存、另存为和未保存确认；大小写、全词和正则查找/替换；机型切换；当前行添加行号、上一行/下一行插入行号及重排行号；真实 VM 运行/暂停/停止、160×80 屏幕、虚拟键盘、点击屏幕后物理键盘输入、居中显示的 `INPUT` 弹层；变量查看及暂停后的编辑、多维数组切片浏览和单元值编辑；内置 WenQuXing 字体的 527 个图形符号面板及 HTML 文档浏览器。`.bas.txt` 保存格式仍由核心库处理，使用原有 GBK 编码。

查找 Ctrl+F、替换 Ctrl+R；Ctrl+H 为当前行添加行号，Ctrl+J/K 在下一行/上一行插入行号，与 Qt 快捷键保持一致。正则使用 Rust `regex` 语法，替换支持 `$1` / `${name}` 捕获引用，零长度匹配可导航和批量替换；不支持回溯引用或前后向断言。普通替换中的 `$` 按原文处理。替换保留编辑器撤销历史。

F1 或“帮助 → GVBASIC 文档”打开内置文档，包含模拟器说明、语义说明、语法扩展、按键值和项目说明；支持页面目录、相对链接、滚动和文本选择。现有 HTML 在编译时嵌入可执行文件，不需要浏览器、CHM 运行库或外部 `docs/` 目录。文档弹层接管焦点，Esc 或关闭按钮返回编辑器。

模拟器现在是独立的系统模态对话框；运行时主编辑器不可交互。编辑器工具栏复用原 Qt GUI 的保存、查找、替换、撤销/重做、剪切/复制/粘贴、启动、停止和符号 SVG；模拟器复用原运行、暂停、停止 SVG，并保留颜色。模拟器布局对照 Qt 版改为左侧 160×80 屏幕及五排虚拟键盘、右侧变量表。编辑器 F5 打开模拟器；对话框内 F5 运行/暂停/继续，F7 停止，关闭对话框会停止 VM。对话框打开时自动聚焦设备屏幕，可直接使用物理键盘。

主窗口采用接近原 Qt 版的紧凑布局：文件/编辑/程序/视图/帮助菜单栏、单排图标工具栏、编辑器/问题列表的上下分隔区、状态栏。文件名和未保存标记显示在系统窗口标题中；工具栏末端是符号按钮、机型下拉菜单和从源码同步机型按钮。菜单只列出已实现的操作。问题列表默认收起，可通过状态栏错误/警告计数展开；展开后可拖动分隔线调整高度，收起再展开会保留高度。问题行可点击跳转到源码，零诊断时也可展开查看空状态。打开文件对话框优先显示进程当前工作目录；Linux 的 zenity 回退也会用该目录初始化。视觉对照依据仓库 `screenshots/` 的 Qt Linux/Windows 截图及旧 Qt 布局源码；Scintilla 编辑器的老式控件外观不还原。旧 Qt 程序未在本轮启动，因为本机没有原版构建所需的 `scintilla521.zip` 和旧 Rust 静态库。

主窗口“视图”菜单可选亮色或暗色主题，工具栏和模拟器窗口也可一键切换（Ctrl+Shift+T）；编辑器高亮、问题列表和模拟器控件会同步切换。模拟器的双功能键将字母/符号保留在中央，数字用强调色显示在右上角。

模拟器虚拟键分别处理按下/释放（包括移出按钮后释放），`CHECKKEY` 可检测持续按住；物理键 Ctrl/Shift 对应求助/中英数，CapsLock 或反引号对应输入法。失焦、窗口停用或暂停会释放按键，物理键与虚拟键同时按下同一设备键时不会相互提前释放。F1–F4 与键盘最后四列对齐。`INPUT` 自动聚焦首字段，Enter 提交、停止程序按钮或 Esc 停止；解析错误保留在输入弹层内。运行时错误和调试反馈显示在模拟器本身，运行时变量编辑按钮禁用。

GPUI Linux 上游会过滤 CapsLock 原始键事件；根 workspace 通过 `[patch.crates-io]` 使用 `vendor/gpui-pre-linux` 0.3.6，仅放行 X11/Wayland 的 CapsLock 按下/释放，保留其他修饰键行为和原许可证。补丁及回归说明见 `vendor/gpui-pre-linux/README.wqxtools.md`。X11 已实测；Wayland 只做编译及公共事件过滤逻辑测试。

尚未完成与原 egui GUI 的全部功能对照：编辑器的中文输入法、长文档性能、文件拖放以及跨平台原生运行尚未充分实测。因此目前不能替换默认入口，也不能宣称完整迁移结束。

本次 Qt 对抗审查修复的 Linux 隔离桌面回归包括连续 `INPUT`、空值纠错、虚拟方向键 `CHECKKEY`、物理修饰键及 CapsLock 按下/释放、F1–F4 对齐、全词/正则捕获替换及撤销、Ctrl+H/J/K 行号操作、文档页面/相对链接和 Esc 关闭。25 个 GUI 包内测试、43 个 Linux 平台测试、两包 Clippy（`-D warnings`）及 release 构建通过；新增回归确保等待 `INKEY$` 时暂停后按键不会意外恢复程序。原 Qt 基线仍为旧源码及仓库截图，而非本次运行旧 Qt。

Linux 隔离桌面已实测中文源码编辑、高亮、诊断消除、运行后屏幕输出、物理键盘 `INKEY$`、暂停后的变量和数组编辑、符号复制、关闭前保存确认、行号与 GOTO 引用重排，以及 `.bas.txt` 中文保存和重开。GPUI 需要 `tree-sitter` feature 才能显示诊断波浪线；语法词法仍由本项目实现。`Document` 的 UTF-16 诊断坐标与 GPUI 的 Unicode 字符坐标已适配。

Windows GNU 目标的 `cargo check` 通过，但 Linux 上交叉编译 Windows release 在上游 `gpui-pre-windows 0.3.6` 处失败：它的 build script 仅在**构建宿主**是 Windows 时生成 `shaders_bytes.rs`，而 Windows release 源码无条件包含该文件。需要在 Windows SDK 环境里原生构建并测试，或等待/贡献上游修复；目前没有可验证的 Windows 单 `.exe` 发布物。Linux 可执行文件仍依赖系统图形库，不是完全自包含。
